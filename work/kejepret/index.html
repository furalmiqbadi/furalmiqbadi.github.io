Masalah

Satu event lari menghasilkan ribuan foto. Pelari sulit menemukan fotonya sendiri, dan fotografer tidak punya cara menjual foto secara aman tanpa takut file asli tersebar.

Peran saya

Frontend designer. Saya mengerjakan tampilan alur pencarian, keranjang, checkout, dan dashboard fotografer dengan Blade dan Tailwind.

Yang saya bangun

Tampilan hasil pencarian wajah dengan pratinjau berwatermark, alur keranjang lintas fotografer, checkout, dan dashboard fotografer untuk mengelola foto, harga, saldo, dan penarikan dana. Tampilan disambungkan ke controller Laravel, panel admin Filament, dan layanan pencarian wajah FastAPI.

Hasil

Satu alur utuh dari selfie sampai unduhan berbayar. Foto resolusi penuh hanya terbuka lewat token UUID setelah pesanan berstatus lunas.

Teknologi

  • Laravel 12
  • Blade
  • Tailwind CSS 4
  • Vite
  • MySQL
  • Sanctum
  • Cloudflare R2
  • FastAPI
