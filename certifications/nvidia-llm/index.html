NVIDIA

Building LLM Applications With Prompt Engineering

Jan 2025

Tentang sertifikat

Pelatihan dari NVIDIA tentang cara menyusun prompt untuk aplikasi yang memakai model bahasa besar. Fokusnya bukan melatih model, tapi mengarahkan model agar keluarannya bisa dipakai di aplikasi nyata.

Topik

  • Struktur prompt
  • Instruksi sistem
  • Konteks dan batasan
  • Evaluasi keluaran

Relevansi

Saya pakai prinsipnya saat menyusun prompt untuk asisten kode dan saat menguji keluaran model di proyek sendiri: instruksi dibuat eksplisit, konteks dibatasi, dan hasilnya diperiksa sebelum dipakai.
