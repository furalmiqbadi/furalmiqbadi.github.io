Notes

Tasks

Money

About

How I work

I work on one problem: keeping a personal app fast and private when the network is not there. Arkustudio is built as a monorepo — shared packages for design tokens, data access and encryption, with each app as a thin feature layer on top.

I care about the boring parts: migration paths that do not lose rows, encryption keys derived on a background isolate so the UI never blocks, and tests around money and cryptography where a silent bug is expensive.
